# WEBUI-API-001 requirements

| ID | Requirement | Verification |
|---|---|---|
| `WEBUI-API-R001` | **Generated GraphOS API client with typed decisions and confirmation flows.** Agent-webui generates a versioned TypeScript client and a single invoke adapter from the Graph OS API schema, and migrates decisions, Markets/apps pages and WebMCP tools to call it; the console confirmation page sends only the exact server-issued plan reference required to complete a previewed effect. | Contract tests against the generated client plus positive and negative effect tests on the confirmation flow verify this. |
| `WEBUI-API-R002` | **Typed ontology, graph, Atlas and object-set operations replace host routes.** Agent-webui's api_extensions.py ontology, graph, Atlas and object-set route blocks, and their corresponding src callers, are replaced by generated Graph OS operations that preserve tenant scoping, purpose context, cursor pagination and existing error semantics. | Cross-surface fixture tests and browser tests covering each migrated route family confirm parity with the prior behavior. |
| `WEBUI-API-R003` | **Remaining domain routes migrate to generated operations with a route census.** Agent-webui's prompts, SDD, knowledge base, sessions, goals, MCP servers/tools and model-management routes in api_extensions.py are replaced by generated Graph OS operations, an architecture lint rule rejects any new unclassified domain route, and a checked-in route census records each route's owning operation, caller, scope and disposition. | Route-census and contract tests plus the lint rule running in continuous integration confirm no unclassified domain route remains. |
| `WEBUI-API-R004` | **Each request carries its own correlation id.** The host mints a fresh correlation id for each HTTP request and WebSocket connection without an inbound `x-correlation-id`. An ambient id bound on the serving thread never leaks into a request. | An observability test binds an ambient id, serves two requests, and confirms two distinct ids that differ from the ambient one. |
| `APIUI-01` | **Generated TypeScript client from a pinned Graph OS schema.** Agent-webui generates its TypeScript types and client from a pinned Graph OS v1 API schema and digest, exposing one invoke adapter and a stable error envelope for all callers. | A regeneration-diff check plus contract tests confirm the generated client matches the pinned schema and envelope. |
| `APIUI-02` | **Typed operations preserve preview-confirm-step-up for effects.** Decisions, Markets/apps pages, WebMCP tools and the console confirmation flow in agent-webui call typed Graph OS operations through the generated client, preserving the preview, confirmation and step-up sequence required before any side-effecting action executes. | Positive and negative effect tests exercise the preview, confirm and step-up sequence end to end. |
| `APIUI-03` | **Ontology, graph, Atlas and object-set operations preserve tenant semantics.** Ontology, graph, Atlas and object-set reads and writes in agent-webui use typed Graph OS operations that preserve tenant scoping, purpose context, cursor pagination and existing error semantics. | Cross-surface fixtures and browser tests confirm semantics are unchanged after migration. |
| `APIUI-04` | **Prompts, SDD, knowledge base, sessions and goals migrate to typed calls.** Agent-webui's prompts, SDD, knowledge base, sessions, goals, MCP servers/tools and model-management features call typed Graph OS operations in place of host-owned routes. | A route census and contract tests confirm each family is covered by a generated operation. |
| `APIUI-05` | **Host drops direct internal imports once replacement operations are proven.** Agent-webui removes direct internal imports and domain route handlers from its host once the replacement Graph OS operations are proven, keeping only an explicitly inventoried set of browser-local endpoints. | A static dependency check and route-census gate confirm no forbidden import or unlisted domain route remains. |
| `APIUI-06` | **Shared auth and streaming are preserved without exposing a service bearer.** Agent-webui preserves shared authentication, credential delegation, streaming and cancel behavior, and error handling across the migration, and never exposes a Graph OS service bearer token to browser JavaScript. | Host integration tests and adversarial browser tests confirm the bearer is never exposed and behavior is preserved. |
